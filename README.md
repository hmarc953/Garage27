## API externa

El formulario Solicitar turno utiliza vPIC de la NHTSA para sugerir marcas y
modelos en el campo «Marca y modelo».

- Documentación: [https://vpic.nhtsa.dot.gov/api/](https://vpic.nhtsa.dot.gov/api/)
- Endpoint utilizado: [https://vpic.nhtsa.dot.gov/api/vehicles/GetModelsForMake/bmw?format=json](https://vpic.nhtsa.dot.gov/api/vehicles/GetModelsForMakeId/0?format=json)
